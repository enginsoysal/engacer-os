WELCOME TO ENGACER OS

START HERE
Your system is installed. No online account or terminal command is needed.
Click a file once to select it. Double-click or press Enter to open it.
Buttons and menu commands use one click. Right-click for available actions.
Escape closes a menu or safely cancels a supported drag.

FIND YOUR APPS
Open Start to search all installed apps and pinned folders. Clear search
returns to browsing. Pinned, All apps and Categories are separate views.
Right-click to customize pins or categories. A taskbar badge counts windows;
choose the particular window when an app has more than one open.

YOUR FOLDERS
Files keeps Back, Forward, Up, Refresh, its address and Places visible.
Home, Documents, Downloads and USB drives are in Places. One click selects a
USB drive; double-click or Enter opens it. Back restores a previous location.
Use Icons or Details. Name, Type and Size sort native folders; USB retains
its directory order. Hover an abbreviated supported name to read it fully.

COPY, MOVE AND RECOVER
Select an item, then use Copy, Cut or Paste, or open Actions.
A menu explains protected, unavailable or busy operations. System files stay
protected. Recycle Bin can restore your recycled files. Permanent removal
always needs a separate review. Deleting a shortcut keeps its original.
During a copy, read the destination and progress. Cancel stops unfinished
work; completed files and copy sources stay. Keep both preserves a conflict
under a new name. Do not disconnect a USB source while copying.
USB provides supported FAT32 browsing and guarded one-file copies. Export is
create-only and has no mid-file cancellation. Use Safe remove when finished.
A disconnected drive keeps its identity instead of opening a replacement.

SAVE YOUR WORK
New document - not saved means no file has been saved yet. Save commits your
text; Save as lets you choose a supported native folder and filename.
Open, Save as and Choose folder share navigation and explicit replacement
reviews. Cancel keeps your current work. Finish or cancel a file operation
before saving another document. If a file changed elsewhere, use Save as
with a new name to keep your edits before reopening the changed original.

MAKE IT YOURS
Settings has Appearance, Display, Input and System. Appearance and Display
have a real preview. Apply and save keeps it; Cancel preview, Escape or
closing its owner restores the earlier choices. Restore defaults previews
this distribution's appearance without reinstalling apps or changing files.
Input choices save separately when clicked. If another file dialog blocks a
Settings action, Show current dialog brings its real owner back to you.
System opens Devices and hardware, Applications, Start and taskbar, and
Quick settings. Remove or reinstall optional apps in Applications. Removing
Calculator does not remove your desktop, Files or base Settings.

WINDOWS AND CONTROLS
Drag a title bar to move a window. Its icon opens the window menu. Caption
buttons minimize, maximize/restore or close it. Closing unsaved text asks first.
Alt+Tab switches windows. A minimized window stays available on the taskbar.
Tab and Shift+Tab move control focus. Enter activates the focused control.
Releasing a button outside it cancels that click. Menus close with Escape.

DESKTOP AND QUICK SETTINGS
My files, Documents, Appearance and Recycle Bin are independent references.
Right-click a built-in icon to hide it; right-click empty space to restore
icons. Your own files and shortcuts remain separate. Use arrow keys or the
page controls when more desktop objects are available.
Windows+A opens quick settings. Network and audio status describe actual
providers. USB actions and Calendar do not require their optional apps.
System messages have Dismiss. They do not close your other windows.

INSTALLATION AND HELP
Use the matching VMware package or ISO and its eight-step installation guide.
Select the disk row, customize your choices, review erasure, install and
choose Restart to Engacer OS. For disk-only startup disconnect only CD/DVD;
keep the installed disk and the same VM. Public unsigned media use Secure
Boot off. Keep the matching ISO for reviewed boot recovery.
More languages, hardware and Windows apps need their own qualified profiles.
