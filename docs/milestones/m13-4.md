# M13.4 - Installation finishes at the installed desktop

Status: in development. M13.3 remains the qualified public download. Development captures are not release qualification.

## Implementation and decisions

Use the shared native typography, controls and existing compositor for installation progress, completion and recovery. Show actual verified backend progress without invented time estimates. Coalesce identical visible progress notifications while retaining storage verification, audio servicing and serial observations. This avoids redundant CPU work without allocating another framebuffer or delaying installation.

Keep recovery actions tied to available capabilities. A live matching ISO can offer supported boot maintenance; a failed installed startup without that ISO explains how to attach it and offers restart and diagnostics. Never present an unavailable repair as a working action. Completion explains the next restart and retained-media behavior.

Report disk capacity using the observed sector width. A correctly displayed capacity does not imply installer write support for an unsupported sector format.

## Required qualification before publication

Freeze the exact media and compiled inputs. Test actual intermediate progress, completion, failure and recovery with owned disposable disks. Review compact, ordinary, scaled and physical 4K frames for readability and clipping. Test the fourteen named enabled-device VMware profiles: SATA, IDE, LSI Logic, LSI SAS, PVSCSI and NVMe with BIOS and UEFI, BusLogic with BIOS, and the exact SATA/UEFI starter. Verify retained-ISO startup, two disk-only starts and persistent user files. Keep the known unqualified QEMU PVSCSI completion behavior separate from real VMware PVSCSI qualification.

Publish matching manuals, exact ISO and VMware assets, source evidence and a freshly saved and checked BrixCanvas homepage before starting M13.5. Universal hardware compatibility and human usability studies are not claimed.
