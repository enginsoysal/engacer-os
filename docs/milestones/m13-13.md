Retain the failed report and media/source identity, diagnose and correct the cause, freeze new bytes and repeat the complete required run. A watchdog or automatic restart cannot turn a failure into a pass. A partial or deliberately interrupted run is diagnostic only.

Then publish the exact candidate, truthful tested limits, English manuals, GitHub evidence and downloads, actual native BrixCanvas Saves and fresh complete public website checks. A named VM workday pass is not a promise of universal hardware compatibility or a human usability study. Only then does hardware recognition become the next development priority.
