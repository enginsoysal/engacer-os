# M13.1 — One native visual and interaction foundation

Status: native implementation and M13-STAGE1-VM-v1 qualification pass. Website rollout and complete public delivery remain in progress; M13.1 is not closed. M12.18 remains the qualified public OS download until the new release is published.

## Changes and decisions

The new native candidate retains the existing smooth Inter masks, semantic font sizes and integer drawing paths. Shared M13 light/dark/high-contrast palettes refine the established component implementation; selected secondary controls use a softer selection surface, while primary actions retain a solid accent. The same production arithmetic is exercised over all 16,777,216 background colors, 1,572,864 state cases and 4,096 scroll geometry cases. Native appearance/input remain separate checks.

Settings → System → Interface preview exercises real buttons, selection and a bounded 48-character input without file or preference writes. It reuses the existing Settings application storage rather than allocating another per-window text buffer or adding an optional-app dependency. Keyboard focus and disabled controls follow the common native control registry.

M13 builds have a separate compiler flag, distribution profile, artifact prefix and external scratch directory. Historical M12 output is never rebuilt. Generated source/debug mappings redact external scratch paths. The existing 8-MiB live-kernel placement check remains enforced; no firmware memory is reclaimed to fit graphics changes.

## Baseline observations before native changes

The unchanged M12.18 ISO with SHA256 `f63b78973c9da269b4eead46873d947e94fcd2266dff4b4c06f2666b743aa3f9` passed an ordinary 1920×1080 / 512-MiB guest and actual 3840×2160 / 1-GiB guest. Each journey installed, restarted with ISO retained, opened Settings through normal Start search, checked stable idle/halted CPUs, then started the installed disk twice without an ISO. Configured guest RAM is not OS consumption. The baseline reports separately record allocator counters and framebuffer bytes (8,294,400 and 33,177,600). These results do not qualify the new M13 candidate or a physical GPU.

An initial test failed because its pointer coordinate cache survived a guest restart. The failed report is retained in diagnostics; the harness now creates a new pointer after restart. No OS fix or pass was inferred from that test failure.
