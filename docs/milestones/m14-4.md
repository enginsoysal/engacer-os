# M14.4 - Original Windows windows and messages

**In development. Not accepted and no M14.4 release is published.** The current tested public download remains [M14.3](https://github.com/enginsoysal/engacer-os/releases/tag/m143-v0.14.3). M14.15 optimization and the complete original-app targets remain mandatory.

## Implementation

The first implementation adds generation-bound native window records, lazy per-GUI-thread queues, checked IPC, synchronous original CPL3 window procedures, creation refusal, subclass/user-data storage, posted/filtered messages, event-driven message waits and teardown. The native compositor bridge hosts original top-level windows using existing movement, resize and caption controls. [Ownership and execution decisions](../architecture/messages-m144.md).
