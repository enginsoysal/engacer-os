# M13.10 - Finish every secondary surface

Status: implementation and qualification in progress after complete M13.9 public closure. No new ISO is qualified yet. Stability investigation, duration tests and reset-chain diagnosis belong exclusively to M13.13.

## Changes, how and why

Settings search now names its results, provides a full Clear search button and uses the result area without irrelevant appearance Apply controls. A pending appearance preview remains explicitly described with the route back to Apply or Cancel. Failed appearance writes explain what is still visible and which recovery action is available, without internal persistence terminology.

Open/Save/folder pickers reuse the same vector Back, Forward and Up icons and semantic control styles as Files. Their existing hit targets, disabled history rules, keyboard focus, owner-bound reviews and filesystem operations are retained. Shared file dialogs gain a consistent semantic header icon and a clear high-contrast boundary. Long paths continue to wrap within the existing bounded metadata area.

Cursor context is refreshed from actual hit targets after a damaged scene is rendered, including keyboard-opened/closed surfaces. This closes stale cursor feedback without an idle worker, heap state, cursor bitmap or extra framebuffer. Existing pointer handling calls the same function. Preview and legacy filename fields receive the text cursor as well.

The offline desktop guide explains pointer feedback. Existing optional-app processes, package identities, file-format limits and independent removal remain intact. No app is made a dependency of the desktop.
