# M14.6 - Open, save and clipboard interoperability

In development after the accepted M14.5 native/public delivery. M14.5 remains the qualified download. No M14.6 behavior or media is accepted yet.

## Ordered implementation

1. Implement bounded fixed/movable global memory with real handle identity, locking, sizes and failure behavior. Clipboard memory ownership must be distinct from ordinary application ownership.
2. Add a session clipboard broker with checked copies across private processes, exclusive open ownership, owner/thread teardown, Unicode text and a native desktop text bridge. Registering a format is not transferring data.
3. Adapt the existing graphical picker to requests from actual foreign windows. Preserve live window/generation ownership, modal routing, cancellation and result buffers. The current blanket rejection while a Windows task runs cannot serve this purpose.
4. Implement the selected OPENFILENAMEW input/output profile and explicit unsupported flags/hooks. Selecting a Save destination does not write a file; the requesting application performs the actual file operations.
5. Qualify real open/edit/save/reopen bytes, Unicode names, cancellation, replacement consent, cross-app text and process cleanup. Keep owned ABI fixtures distinct from original application tasks and retain all mandatory original targets.

## Acceptance and limits

Run compact, ordinary and actual 4K profiles, retained runtime/file/window/menu/control regressions, original supported MSI/console tasks and the exact enabled-device VMware installation/two independent starts. Inspect saved bytes independently after stopped-disk reads and a new boot. Repeated close/cancel/failure paths must not retain owned pages or leave another app locked out. Bound metadata and clipboard bytes, allocate lazily and block waiting threads instead of polling.

Notepad++, SumatraPDF and the final original task corpus remain mandatory. Required runtime dependencies must be implemented when a real task reaches them; a synthetic fixture or an import name is not original application compatibility. M14.15 whole-system optimization remains blocking.
