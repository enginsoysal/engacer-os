# M13.6 - Familiar Start, taskbar and system tray

Status: native implementation and qualification in progress. M13.5 remains the current qualified download until the new exact media pass. M13.7-M13.12 have not started.

## Decisions, implementation and alternatives

Use the existing bounded Start catalogue, original app icons, preference schema and local name/alias search. Replace horizontal grid cards with recognizable 40-unit icon tiles and a readable label below. Shared column/row geometry drives rendering, hit targets, pagination and arrow navigation; search and the explicit List choice retain the compact descriptive list. No index worker, web runtime, app process per keystroke or new persistent schema is added. Empty results retain Clear search and All apps; categories and customization remain optional.

The taskbar keeps stable app identity, generation-bound window groups and per-user left/center alignment. Reduce each app group from 140 to 112 logical units, retain a short readable label and original icon, and reserve a count badge for multiple real windows. Quiet unopened pins do not have a permanent raised-button border. Hover/focus/pressed and active states remain distinct; running, active and all-minimized indicators derive from actual windows. Overflow retains bounded menus and explicit window selection rather than hiding inaccessible work. Caption/menu ownership and dirty-work reviews remain authoritative.

The existing slot-free system tray retains real network/USB/audio and UTC-calendar providers. Unsupported Wi-Fi, Bluetooth and battery controls remain explained rather than fabricated. Volume changes during an owned picker stay session-only; replacement USB generations cannot receive an older held action. Reuse this working provider model instead of introducing decorative switches.

## Verification plan

Exercise five actual display/scale profiles, real local search/launch/pin/unpin/category/list/keyboard tasks, grouped and minimized windows, overflow, optional-app removal, power cancellation and exact persisted preferences across independent disk-only starts. Exercise actual USB replacement, safe removal and independent imported bytes, provider unavailable/empty states and ownership. Measure fixed/peak/retained memory separately from framebuffer/configured RAM and verify idle halt. The exact enabled-device VMware starter must install, restart with ISO retained and start twice without it. Inspect native captures for readability and consistent states. Publish updated English guides, exact release assets and fresh complete public website proof before M13.7. Agent scenario review is separate from a human novice study.

## Development review and retained findings

The first original-icon grid candidate exposed visibly left-aligned labels under centered icons. The replacement centers labels using actual font measurement and bounded clipping. A later native keyboard capture exposed weak focus contrast on the dark taskbar; the final candidate adds an explicit white focus rectangle instead of using the light-content ink color. Superseded candidate media and observations remain preserved outside OneDrive and are excluded from qualification.

The initial full taskbar fixture reached the documented eight-window quota while an earlier Editor remained open, then correctly refused Help as a ninth window. The test now explicitly focuses the generation-bound Editor before closing it and checks zero-window preconditions around optional-app and pin tasks. The initial [observation](../../evidence/M13/6/diagnostics/initial-window-quota.json) is retained; it is not a pass or evidence of unsupported unlimited windows.
