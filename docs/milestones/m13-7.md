# M13.7 - Files as the everyday workspace

Status: native implementation and qualification in progress. M13.6 remains the qualified download. M13.8-M13.12 have not started.

## Design and implementation

Keep the installed native filesystem, USB providers, generation-bound history and cooperative transaction engine. Use one compact two-row navigation/command frame with original place icons and a quieter 192-unit sidebar. Retain Back, Forward, Up, Refresh, breadcrumbs/address editing, details/icons, sorting, context actions and page navigation. Compact windows expose optional commands through More and Places instead of overlapping buttons.

Ctrl+F focuses a bounded current-folder filename filter. It matches displayed names case-insensitively in native system folders, with at most 63 ASCII query bytes per window. Changing a query clears hidden selection and scroll offset; Enter selects the first result and never launches it directly. Escape clears a query before leaving its field. Clear, navigation, generation reuse and successful create/copy/move have explicit state transitions. Refresh and sorting preserve the same-folder query. Recycle Bin names use their original displayed identity; Empty Bin requires clearing the filter first so hidden items cannot be permanently deleted accidentally.

USB filtering is explicitly unavailable. Its disabled field says System folders only; real drive navigation, transfers and safe removal retain their existing capability guards. A whole-disk index, recursive search, background worker, persisted query and new per-window process are deliberately excluded: the current-folder bounded scan reuses the existing listing cache and needs no heap cache.

## Qualification findings

An initial zero-result observation found that the rendered empty state skipped rebuilding its old sorted-list cache. Native drawing now refreshes the same bounded cache even for zero matches. A later keyboard journey found that Enter on a single native folder launched a new Files window while mouse activation navigated in place; the single-folder keyboard/context route now navigates the same generation-bound owner before applying the new-window quota. Desktop launches and explicit multiple/new-window operations retain their separate behavior. An actual USB capture also exposed a clipped Safe remove label; the button now says Eject, while its existing flush-before-removal contract is unchanged. Earlier unqualified candidates and failed observations are retained as diagnostics; cancelled or older-media checks do not qualify the corrected ISO.

A later actual minimum-window disk-start task exposed breadcrumb/address hit ambiguity when the remaining address field was under 150 units wide. Such fields now use one explicit Address button, preserving a real mouse path to editing instead of overlapping the root breadcrumb. The compact boot task uses the visible Places menu when the sidebar is absent. Active transfers retain the larger footer reservation even after Refresh clears the notice; this keeps progress and Cancel within the existing bounded repaint area. Earlier candidate reports do not qualify corrected media.

The bundled offline Welcome guide also describes More, Eject, the compact Address action and the actual current-folder filter. It ships inside the qualified media, rather than leaving the user to discover changed labels only on the website. Active-transfer observation now pauses only to read a complete owner/window/tray control snapshot, avoiding a transient registry prefix during painting; it never changes guest memory or forces a paint. Timing measurements remain separate.

Global Alt navigation and Alt+D address editing take priority over the focused query text. The native keyboard task exercises both while filtering so a navigation shortcut cannot append a letter to the query instead.
