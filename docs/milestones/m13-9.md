These primary sources support a host sampling limitation, not a claim that all measured delay is external. Native trace results and actual visible pixel confirmation therefore remain separate mandatory observations. The original external targets are retained as unmet goals where observed; stage delivery makes no end-to-end frame-rate guarantee. No timing measurements from previous candidates qualify the new cursor candidate. This method decision is recorded before its reference qualification and must be prominent in the stage release limits.
