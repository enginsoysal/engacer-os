# M13.11 - Complete supported personalization

Status: exact M13-STAGE11-VM-v1 native qualification passes. Matching GitHub and actual website delivery are the remaining closure gates. Stability investigation remains exclusively M13.13.

## How and why

Retain existing validated appearance, display, input, accessibility, Start and taskbar preferences. Qualify preview/apply/cancel/defaults, malformed records, actual persisted bytes, independent optional-app removal and distribution defaults. Finish the High-contrast Start perimeter and current Files-place boundary using existing primitives, without a pixel cache.

The optional screensaver is an Off-by-default native Settings feature under Appearance, rather than another application process or catalog entry. This keeps one discoverable owner, avoids a duplicate launcher/window and preserves all existing package and appearance record identities. Off disables idle presentation. It remains independent of every optional app, including Clock. Its absence from an application list is deliberate: no standalone screensaver application is claimed.

A separate strict twenty-byte per-user record holds magic/version, enabled, timeout and style. Supported timeouts are one, five and ten actual idle minutes; implemented styles are Engacer logo, Clock and Blank. Malformed or unreadable records fall back to Off. Existing distribution recipes retain their branding, wallpaper, theme and optional-app defaults. The screensaver starts Off in every recipe and is configured per user through Settings; schema 3 does not expose a screensaver-default field or permit writing this system preference through a data package. No unsupported recipe switch is introduced. Saved choices, temporary edits and preview are separate. Apply saves; Cancel, leaving the page or closing restores the saved choices. Competing Settings windows cannot overwrite another draft.

The saver reuses the current framebuffer/shadow buffer, existing timer wakeups and native renderer. No background process, extra framebuffer or polling loop is added. Decorative logo position changes are bounded to once per second, Clock updates to once per minute, and Blank has no animation. Shared-service damage may still request an ordinary redraw. Reduced motion keeps the logo still. Input wakes the desktop with its windows, files and dirty documents retained; this is neither authentication nor display power management.

Genuine physical keyboard changes, raw motion even at a clamped edge, wheel and button changes count as activity. Identical periodic USB reports and network/timer work do not. Physical key holds are tracked independently from translated keydowns, modifier toggles and repeat counts. Preview waits for its activation gesture to finish. Wake consumes its complete gesture through released keys/buttons, drained queues and a short quiet guard, preventing click-through and stuck interaction state.
