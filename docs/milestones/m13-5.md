# M13.5 - A finished desktop and window experience

Status: in development. M13.4 remains the qualified public download. M13.6-M13.12 have not started.

## Decisions and implementation

Replace the permanent desktop brand banner with a top-aligned shared icon grid. Rendering, pointer hit testing and keyboard neighbors use the same bounded geometry. Full-name feedback moves into a reserved strip above desktop paging. Readable small label backings preserve contrast over customized wallpaper without another framebuffer.

Render an original folded-light wallpaper using integer horizontal spans within damaged rows. Solid and Horizon choices remain available, and high contrast stays plain black. No image decoder, timer, worker, cache or new retained pixel buffer is added. This preserves distribution color choices while giving the default desktop an original identity.

Keep the existing caption hit areas and window ownership. Refine active/inactive borders into restrained hairlines; high contrast keeps a stronger outline. Snap preview shares the actual target geometry, including odd-width right halves, and states how to apply or cancel the active drag. The underlying move/resize/minimize/maximize/restore/snap implementation remains authoritative.

## Required qualification

Review compact, ordinary, 150% and actual 4K frames. Exercise two-window tasks, pointer and keyboard geometry, dirty-work ownership, off-screen recovery, independent starts and persisted files/preferences. Measure fixed/peak/retained memory and idle halt separately from configured RAM. Publish the exact ISO/VMware assets, updated guides and freshly saved/checked public website before M13.6. Still pictures do not qualify motion targets, GPU acceleration or universal hardware.
