# M13.8 - Settings, errors and recovery form one product

Status: implementation in progress. M13.7 remains the qualified download; no M13.8 native or public completion is claimed.

## Design and decisions

Keep the existing native preference transactions, generation-bound windows, modal ownership and independent optional applications. Add a bounded, per-window category search over actually supported settings. Results open real categories; the search never invents hardware switches. A common search row and consistent category tabs preserve the existing ordinary mouse and keyboard routes. Increase the Settings minimum height to fit the extra row without reducing readable text or overlapping its Apply/Cancel and status areas. Compact reference displays still fit this minimum.

Appearance and display changes remain explicit previews. Apply writes the actual user record; Cancel or close restores the previous session values. Restore defaults previews the distribution values and does not reset files or optional apps. Input and accessibility choices retain their separately labelled immediate-save behavior. Search does not apply a preview or steal a file dialog. Escape clears/leaves search before cancelling a preview.

Use the shared semantic muted color for empty search hints, including Start. Place ordinary dismissible shell feedback near the bottom of the workspace, with one shared draw/hit rectangle and caption avoidance, rather than covering primary top-right caption controls. Retain message accessibility and explicit Dismiss; do not add a polling worker or a full-screen surface.

## Required native qualification

Five display/control profiles, actual search/category navigation, Preview/Apply/Cancel/Restore defaults, refused display size and modal ownership, two-window preview arbitration, independently read saved preferences and two disk-only starts. Remove and restore an optional app without breaking Files/Settings; cancel dirty work and inspect unavailable USB recovery. Inspect applied light/dark/high-contrast frames and caption-safe feedback. Bind exact source/media, fixed/peak/retained resources and the actual enabled-device VMware package. Final integration and latency qualification remain M13.12 and M13.9 respectively.

## Public delivery

Matching English current guides, release assets, independent downloads, native Brix homepage/recovery Saves and fresh complete public desktop/mobile/search/source/link verification are required before M13.9. Continue using the existing BrixCanvas publication features; report a missing platform capability to the owner rather than modifying the platform.
