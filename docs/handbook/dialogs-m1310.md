# Open, save, review and recover in Engacer OS M13.10

Candidate guide; matching native acceptance and public media must be published before this is a qualified download. Stability qualification remains M13.13.

## Find the file or folder

Open and Save as share the same Back, Forward and Up icons as Files. Disabled arrows mean there is no earlier/later location. Home, Documents, Downloads and Pictures are visible choices. The address field accepts an existing native folder. One click selects a row; double-click or Enter opens it. Escape or Cancel returns without committing the choice.

These pickers browse native folders. For USB files, first copy them into Downloads using Files. This restriction is also visible in the picker. Back and the address field remain available when a location is empty or unavailable.

## Save a separate copy

Use Save as, choose a folder, enter a name and select Save. The Text type adds .txt only when you omit an extension. New folder asks for its own valid name before creating it. An invalid name is explained without creating a partial folder.

An existing destination gets a separate Replace file review. Back lets you change the choice; Cancel keeps the current document and its path. Replacement requires its explicit button. The default Enter action does not silently overwrite the target.

## Keep unsaved work

Opening a different document while the current one is dirty asks whether to Save and open, Discard and open, go Back or Cancel. Back/Cancel preserve the exact unsaved text. Save and open must successfully save before the selected source is opened. A review remains attached to its actual window even when another window is used.

If another window changes the reviewed destination, the old replacement review is refused. Review the current file again. A write error keeps the document and recovery controls; it does not report installation or save success.

## Inspect and choose safely

Properties shows actual type, size and location. Long locations wrap, and High contrast gives the dialog a clear boundary. Close leaves the item unchanged. File-copy conflicts retain safe choices such as Keep both, Skip matches and explicit Replace files. Cancellation does not discard unrelated documents.

Image Viewer opens supported BMP files with the common picker. Archive Manager opens supported ZIP files and chooses an extraction folder through the same navigation. File-format and storage limits remain real limits, not hidden successful substitutes.

Pointers reflect supported editable fields and resize edges. Keyboard opening/closing of surfaces refreshes the pointer even when the mouse stays still. F1 names a focused control; Tab/Shift+Tab and visible buttons remain available.
