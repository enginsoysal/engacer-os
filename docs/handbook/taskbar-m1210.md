# Use the grouped taskbar — M12.10

Development guide. Qualification and public M12.10 downloads are still pending;
the completed tested download remains [M12.9](install-m129.md).

Each app has one taskbar button, combining its pin and open windows. The icon
and name identify the app. A number appears when it has several windows. The
active app is highlighted with a wide line. Other open apps have a short line;
minimized-only groups show dots. An unopened pin has no running indicator.

- Click an unopened pin to launch its installed app.
- With one window, click to bring it forward or restore it. Clicking its active
  window's button again minimizes it.
- With several windows, choose the desired row in the window menu. Its number
  identifies the live window, its name identifies the folder/document, and
  minimized or unsaved state is shown where applicable.
- Use **Open new window** in that menu for another instance. The existing
  eight-window limit remains; close a window if the desktop explains that limit.

**More apps** contains hidden pinned and running apps. Selecting one restores
or focuses its window; several windows open the same chooser. Next/Previous
apps appear when another menu page is needed. More apps is highlighted when
the active app is hidden there. Focus changes keep the existing app order.

Right-click an app button to open another window or change its Start/taskbar
pin. A single running window also has Minimize/Restore and Close window.
Unpinning keeps your app, files and open windows. A running unpinned app stays
on the taskbar until its last window closes. Use **Start → Customize → Taskbar**
to reorder pins or change alignment; these choices save per user.

To use the taskbar with a keyboard, click an empty desktop area, then Tab to the
required control and press Enter. Window menus support arrow keys and Enter;
Escape closes the menu. Start search remains another way to launch an app.

Closing a dirty document asks for a decision. Keep editing preserves your work.
Finish or cancel a window's file dialog before trying to minimize or close its
owner. Software Manager refuses to remove an app while its windows are open;
close them first, then confirm removal. It removes stale pins without removing
the desktop. Required base components remain protected.

This stage groups native app identities. It does not add Windows compatibility,
preview framebuffers, GPU drivers or a higher process/window quota. Shared
menu/transfer feedback, scale/cursor work and final regression retain their
later M12 milestones. Agent tests are separate from human usability studies.
