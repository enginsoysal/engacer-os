# Files navigation in M12.5

Development guide: M12.5 qualification is in progress. Use the handbook index
for the current tested download until the matching release is published.

Open Files from Start or double-click a desktop folder. Click once to select a
folder or drive; double-click it, or press Enter after selecting it, to open it.
The title and address describe the location you are actually viewing.

Back and Forward revisit locations in this window. Up opens the parent folder;
at a USB drive root it returns to USB drives. Refresh checks the current
location. Home and the Places choices return to your ordinary folders. Narrow
windows keep Places as a button instead of squeezing in a sidebar.

Choose USB drives in Places, select your connected drive, then double-click or
press Enter. The same navigation controls remain available when no drive is
connected. Back returns to the folder you came from. Connect a supported FAT32
USB drive and Refresh to see it in the drive collection.

The Page controls browse additional items in a large folder. They do not change
your location history. Back also restores the page you were viewing. Each window
keeps its own last eight locations. Ctrl+N opens the current location in a new
window with independent history.

Select a USB file and choose Copy to Downloads to import it. These USB operations
retain their existing FAT32, one-file and create-only limits. Unsupported actions
are unavailable. Safe remove finishes outstanding work before unplugging; wait
for confirmation before disconnecting the device.

If a drive disappears, its previous location stays unavailable. Back and Home
still work. Plugging in another drive never silently changes that old location
to the replacement's contents. Return to USB drives and explicitly open the
connected drive to use it.

Optional address editing accepts ordinary native paths and named places. A USB
address such as `USB:2:/Games` identifies a drive and folder. Relative USB paths
stay on the current drive; an absolute `/...` address chooses a native folder.
Invalid or overlong addresses leave your previous location intact and keep the
field open for correction. Escape cancels editing. Browsing needs no address
syntax or terminal commands.
