# Keyboard and accessibility — M12.16

M12-STAGE16-VM-v1 native qualification passes. Use its matching M12.16 media; complete public delivery passes with twenty downloads, 395 pages, 2,749 HTTP links and native browser verification. M12.17 follows in order.

## Open Accessibility

Open Settings and choose Accessibility. High contrast uses clear black, white
and yellow controls while keeping your normal appearance saved separately.
Turn it off to return to that appearance. Reduced motion removes decorative
shadows and moving/hovering control effects. Actions stay immediate. Reset
accessibility turns these two choices off; it does not reset your apps, files,
keyboard layout or normal appearance. Choices save immediately when activated.

You can reach the same page with the keyboard: open Start, type settings and
press Enter. Use Tab or Shift+Tab to focus Accessibility, then Enter. Focus the
checkbox you want and press Space or Enter. The visible checkmark shows its
state. A clear border identifies the focused control.

## Move around without a mouse

- Tab and Shift+Tab move between the available controls in the active pane.
- F6 changes between the current window, taskbar, desktop and a visible system
  message. Shift+F6 goes in reverse. Empty or unavailable panes are skipped.
- Enter activates a button or opens the selected item. Space also activates
  supported buttons and checkboxes; typing spaces still belongs to text fields.
- Arrow keys move the selection in supported file, desktop and menu views.
- F1 opens Focus Help with the current control's name and role.
- Escape closes Focus Help and returns to its original control when available.
  It does not accept a file review or discard a document underneath the help.
- Existing Alt+Tab, Alt+F4, context-menu and file-navigation shortcuts retain
  their documented behavior. Closing unsaved work still asks for a choice.

To dismiss a system message, use F6 until its Dismiss button is focused and
press Enter. Start, Files, Settings and the taskbar remain base services; these
routes do not require optional Calculator, Clock or Text Editor packages.
F6 does not steal focus from an active file review, first-start guide, menu,
tray or drag. Finish or safely cancel that interaction first.

## Readable size

Settings → Display offers Automatic, 100%, 150% and 200% when the physical
screen leaves at least logical 800×600. Apply and save keeps a display preview;
Cancel preview restores the previous size. Unsupported choices keep the current
size. For example, 1280×1024 cannot provide logical 800×600 at 200%.
The ordinary installer supports compact 800×600. Advanced partition tools still
need logical 1024×768; use a larger screen or smaller scale for them.

## Saved choices and scope

Accessibility saves independently from Appearance and Input. If saving fails,
the old accessibility choices stay active. Invalid saved accessibility data
uses safe defaults; Settings explains how to save a valid new choice.
Native Focus Help provides visual names and keyboard instructions. An external
screen reader and speech service are not implemented or qualified by this stage.
See the matching release for actual virtual-machine, scale and resource tests.
