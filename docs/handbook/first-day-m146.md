# Your first day with M14.6

Native/source/media qualification passes for build 5f49030d412bd7f0587568c029becc2c. Public release/download and complete website verification are pending; M14.5 remains the last completed public delivery.

Start with the [matching VMware installation guide](install-m146.md) and [release limits](../releases/m146-v0.14.6.md). M14.6 retains the native desktop, file/settings and process/thread profiles and adds cross-app Unicode text transfer, bounded shared Open/Save dialogs, scalar text rendering and exact saved/reopened document bytes. The optional Firefox installer remains download-only. This is development media for the named test profiles.

## Find your way around

Click an item once to select it; use the configured double-click or Enter to open it. Open Files for Home, Desktop, Documents and Downloads. Back, Forward and Up navigate folders. Start search finds installed native apps. Right-click or Shift+F10 opens the available context menu. The taskbar switches between open windows.

The retained desktop, Files and personalization controls are explained in the [desktop guide](desktop-m135.md), [Files guide](files-m137.md), [Start and taskbar guide](start-m136.md) and [Settings guide](settings-m1311.md). Their original qualification records remain historical; the matching M14.6 release records the new media's actual tests.

## Try the Windows changes

Open **Windows Apps** from Start. Install the included original 7-Zip profile, run its supported console actions and try the sample archive/extraction tasks. **Open file manager** starts its original Windows GUI window: try moving, resizing, minimizing/restoring and closing it. Click Documents once to select it and double-click to open it. Double-click a folder to enter it; Backspace returns to its parent. Help > About opens the original dialog; OK returns to the file manager. Follow the matching Windows guide for original filename copy into Text Editor and the original Browse/cancel/Unicode destination preview. Selecting Save in that preview chooses a path; it does not create an archive. Full GUI archive and arbitrary app tasks remain later gates. **Check a Windows file** inspects an original AMD64 EXE/DLL without starting it. This helps explain loader compatibility; it does not mean every Windows installer or GUI works.

Open **Browser > Browser choices** for the original Firefox x64 installer download. Downloads shows progress and offers Cancel. A successful download is saved in Downloads; it does not run automatically. Firefox installation and execution remain unavailable. Follow the [Windows and browser tutorial](windows-m146.md) for the exact distinction.
