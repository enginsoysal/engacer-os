Click **Start**, or press the Windows key. Type an installed app's name or a
pinned folder's label. Search stays on this device. It does not search the
Internet or all your files. Exact names appear before prefixes and other partial
matches. Results identify apps and their categories, or pinned folders.

Use **Pinned** for your shortcuts, **All apps** for installed apps, or
**Categories** and its category selector. **List**/**Grid** changes presentation;
search remains a full-width list. The heading shows the visible range and total;
use the bottom arrows to see the next or previous page. Click a result to open it. In Start, arrows
select a result and Enter opens it. Tab moves between controls. Escape first
clears a search, then closes Start. Shift+F10 opens the selected result's menu.

Right-click an app to pin or unpin it from Start or the taskbar, or move it to a
category. **Customize** manages category labels, visibility and order, Start
pin labels/order, and taskbar pins. A renamed pin still launches the same app.
Hiding a category does not hide its apps from All apps or search. Unpinning
does not uninstall an app or delete a folder. Optional app removal belongs in
Software Center; required shell components remain protected.

To pin a native folder, select it in Files, right-click and choose **Pin folder
to Start**. The pin references the folder rather than copying its contents.
An unavailable folder reports that condition instead of opening another path.
USB locations are not native folder pins.

If there are no results, try a shorter name or choose All apps. A removed app
does not remain searchable. If eight windows are already open, close one before
opening another. A failed preference save reports that changes last only for
the session; check space or recovery before expecting them after restart.

**Power** opens Restart/Shut down choices and a separate review. Save documents
and finish transfers first. Cancelling a power review keeps the session running.
**Restore defaults** also requires review and changes layout only; your files
and installed apps remain.
