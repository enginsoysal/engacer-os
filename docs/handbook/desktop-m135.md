# Your Engacer OS M13.5 desktop and windows

Development guide: M13.5 qualification and publication are in progress. M13.4 remains the qualified download until that delivery finishes. Later Start, Files and Settings refinements remain separate stages.

## Start with your desktop

The large desktop name banner is replaced by an uncluttered workspace. My files, Documents, Appearance and Recycle Bin have recognizable icons at the left. One click selects an item. Double-click or Enter opens it. Buttons and menu commands need one click. Right-click shows the actions available for that object. Escape dismisses a menu or safely cancels a supported drag.

Selected objects have a filled highlight; keyboard focus has an outline. A small backing keeps labels readable over your wallpaper. Long desktop names have a full-name strip above the desktop paging controls. When a desktop has more objects than fit, use Previous/Next or the keyboard to reach the other page. Home/End and arrows operate on actual visible object positions.

Right-click a built-in reference to hide it. Hiding Appearance does not remove Settings or delete your files. Restore desktop defaults restores the built-in references. Your own files and folders remain separate. Use the existing Files and Recycle Bin actions to manage real items.

## Move, resize and switch windows

Drag a title bar to move a window. Drag a side or corner to resize it. Escape cancels an active move/resize and restores its previous position. A window can partly cross a screen edge while keeping a reachable title-bar area. To bring it back, use its window menu, **Move (arrow keys)**, the arrow keys and Enter; Escape cancels. Alt+Space opens the focused window's menu. Win+Up maximizes it.

The caption buttons minimize, maximize/restore and close. A subtle border and title distinguish the active window. Minimize keeps your work. Choose its taskbar app to return; if several windows belong to the app, choose the particular window. Alt+Tab switches between windows. Closing an unsaved document asks what to keep; simply moving, switching or snapping cannot discard its text.

## Put windows side by side

Drag a title bar to a screen edge. The outline describes the actual proposed position; the label tells you how to apply it. Release to place the window, or Escape to cancel. The left and right choices require enough room for the app's minimum size. A refusal explains when Maximize is the suitable choice.

After placing one half, choose another existing window for the other side, or Escape to keep that side unchanged. This chooser is temporary; finish or cancel it before using the taskbar. Win+Left and Win+Right provide explicit keyboard snap choices. Win+Down restores the window's own normal rectangle. Keyboard Move uses its arrow-key position, without creating a snap from a virtual off-screen cursor.

## Make it yours and keep it readable

Open Appearance, or find Settings from Start. The Gradient wallpaper now uses the original folded-light artwork. Solid is plain; Horizon keeps a soft wash. Ocean, Night and Paper remain supported color choices. The artwork is drawn within damaged rows without another wallpaper image buffer. High contrast keeps a plain black backdrop.

Settings > Display offers supported automatic or explicit sizing. Use Preview/Apply/Cancel as shown. A size that cannot fit is refused with a readable fallback. The named native profiles include ordinary, compact, 150% and actual 4K/200% captures; this is separate from universal physical hardware or GPU acceleration.
