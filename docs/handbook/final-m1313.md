# Your first day with Engacer OS M13.13

Use the [matching installation guide](install-m1313.md). Complete the real installation and choose Restart to Engacer OS; the installed desktop must open even when the ISO remains attached. Keep the ISO available for recovery. For disk-only startup disconnect only CD/DVD, keeping the same installed disk and firmware mode.

## Start with familiar actions

One click selects; double-click or Enter opens. Right-click offers actions for the current target. Use Start to search installed apps. The taskbar switches existing windows; minimize, maximize/restore and close remain separate. Drag a title bar to move a window. [Desktop and windows](desktop-m135.md), [Start/taskbar/tray](start-m136.md).

Files provides Back, Forward, Up, a current location, folder navigation, selection, filtering, paging and supported transfers. USB drives appear only when a supported readable device is actually connected. Opening a drive does not format it. Use safe removal before unplugging. [Files](files-m137.md), [transfers](transfers-m137.md).

Use Save or Ctrl+S to retain Text Editor work. Open and Save dialogs belong to their requesting window. Closing with unsaved edits offers explicit choices. A reset is not a save operation. [Dialogs](dialogs-m1310.md), [saved work and stability](stability-m1313.md).

## Make it yours

Settings offers supported theme, accent, wallpaper, text size, keyboard and pointer choices. Preview changes, Apply to keep them or Cancel changes to restore saved choices. Search Settings with Ctrl+F. The optional Screensaver starts Off; its first wake gesture is consumed safely. It is not a password lock or a freeze repair. [Personalization](personalization-m1311.md), [Settings](settings-m1311.md), [accessibility](accessibility-m1216.md).

Optional apps are separately removable; removing Calculator does not remove the desktop, Files or Settings. [Apps](apps-m1310.md). Developers can build supported distribution profiles without bypassing disk safety checks. [Distribution profiles](../architecture/components.md).

## Know this release's scope

M13.13 closes the owner-revised ninety-minute-plus observation scope, with separately verified exact-candidate data, startup, resource, screensaver and labelled recovery tasks. The earlier eight-hour/two-hour gate was stopped at explicit owner direction and did not pass. The cause of historical natural freezes is not independently established. This is development media with named virtual scope, not universal hardware/stability or general Windows application support. [Exact release](../releases/m1313-v0.13.13.md).
