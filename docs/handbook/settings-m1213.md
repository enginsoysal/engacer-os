# Settings and personalization — M12.13

M12.13 passes its named native qualification. Use the matching
[installation guide](install-m1213.md) and [release scope](../releases/m1213-v0.12.13.md).

Open Settings from Start. Choose Appearance, Display, Input or System.
Tab chooses a visible control and Enter activates it. Categories retain the
same shared controls, spacing and readable feedback.

## Preview your appearance

Appearance offers accent colors, Light/Dark, wallpaper and pattern. Default
uses this distribution's accent. Display offers Automatic, 100%, 150% and 200%;
an unsupported size explains that you need a smaller choice.

- **Apply and save** keeps the appearance for your next start and saves normal
  app window sizes. Wait for the saved message; a failure keeps the preview.
- **Cancel preview**, Escape or closing that Settings window restores the
  previous session appearance without saving. Display changes reflow windows
  to keep them reachable; independent window arrangements are not undone.
- **Restore defaults** previews the distribution's appearance and Automatic
  display size. Apply saves it; Cancel restores your previous choice. Apps,
  files, Start pins and input preferences are unaffected.

Finish a file dialog before changing or cancelling display size. Finish/cancel
file operations before saving preferences. If another Settings window owns a
preview, use Apply or Cancel there first; its preview is not overwritten.

## Mouse and keyboard

Input offers Fast (200 ms), Normal (500 ms) and Slow (900 ms) double-click
intervals. A single click still selects; double-click opens. Choose the interval
that is comfortable for you. Supported keyboard choices are US QWERTY and US
Dvorak. **Input choices save when clicked**, independently of visual preview.
If saving fails, read the message rather than assuming restart persistence.

## System and recovery

System opens Devices and hardware, Applications, Start and taskbar, and Quick
settings. Removing optional apps does not remove Settings or the base desktop.
Devices Back returns to System. Keep personal files separate from app removal.

If saved appearance cannot be read or validated, safe defaults remain usable.
Settings explains the fallback. Review your choices and use Apply to save a
valid replacement. Missing preferences are normal on a new installation.

This stage does not broaden hardware, filesystem, GPU or Windows app support.
