# Standard apps and independent removal in Engacer OS M13.10

Use the matching M13.10 testing release. Exact native functional qualification passes; stability remains M13.13. [Release scope](../releases/m1310-v0.13.10.md).

Files and Settings belong to the base desktop. Optional applications use separate catalog identities; removing Calculator does not remove Files, Settings, the taskbar or your personal documents. Use Software Manager to manage available optional apps. Hiding a desktop shortcut does not uninstall its app.

| Application | Current purpose |
|---|---|
| Files | Native folders, supported USB browsing and safe file operations |
| Settings | Supported appearance, display, input, system and accessibility preferences |
| Text Editor | Native text documents and shared Open/Save reviews |
| Calculator | Lightweight arithmetic |
| Downloads | The implemented native download flow |
| System Monitor | Actual system/resource observations |
| Terminal | Advanced native commands |
| Clock and Calendar | Time and supported calendar tasks |
| Disk Utility | Supported disk inspection and guarded operations |
| Software Manager | Optional app management |
| Update & Recovery | Implemented recovery choices and their real limits |
| Archive Manager | Supported archive operations and folder choice |
| Image Viewer | Supported native BMP viewing |
| Screenshot | Native screen capture |
| Media Player | Supported media/audio operations and available provider status |
| Browser | The implemented native browser surface, with its existing limits |
| Help | Included offline desktop guidance |
| Windows Apps | The existing explicitly limited Windows installation/application profile |

One click selects desktop files; double-click or Enter opens them. Start and taskbar buttons use one click. Each real app window has its own caption controls. Minimize keeps it on the taskbar; Close affects that window, with an explicit review for unsaved work where applicable.

The native frame matrix checks all nineteen base/optional window kinds in Light at five display profiles, plus all nineteen in Dark and High contrast at ordinary size. Shared controls and secondary dialogs separately cover all three themes at every profile. This does not claim every app supports every Windows format or Internet service.
