# Messages and recovery — M12.14

M12-STAGE14-VM-v1 native qualification and complete public delivery pass: twenty downloads, 375 pages and 2,617 HTTP links, native homepage Save and fresh desktop/mobile verification. M12.15 follows in order.

- A shell message appears in a small card. Choose Dismiss when you have read it. Existing windows remain open.
- A grey file action is unavailable for the current selection, folder or active operation. Read the explanation at the bottom of the menu. Use Home for your own files; close an app using an item before moving, renaming or recycling it.
- When a copy is running, wait or choose Cancel in its Files window before saving another document or opening a file dialog. Unsaved text stays open.
- If Settings asks you to finish a dialog, choose Show current dialog. Complete or cancel that review, then return to Settings. This button does not approve the review for you.
- Search in Start covers all installed apps and pinned folders. Choose Clear search to return to your browsing view. Clicking Pinned, All apps or Categories also leaves search.
- New document - not saved means that no file has been saved yet. Choose Save or Save as. A failed save keeps your text. If another window changed the same file, use Save as with a new name to keep your edits before reopening the changed original.
- If a USB source disappears while copying, reconnect it and select it again. An unfinished destination is not presented as a successful completed copy. Keep the source connected until the operation finishes and use Safe remove.

See [the desktop guide](desktop-m12.md), [Settings](settings-m1213.md) and [implementation decisions](../architecture/feedback-m1214.md). Hardware and foreign-application support are limited to the named qualified profiles.
