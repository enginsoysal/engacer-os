# M12 final qualification — M12.18

Use the matching [installation guide](install-m1218.md) and final release media.
M12 is a familiar, customizable native desktop on the independent Engacer OS kernel.

## Everyday controls

- Click a desktop or Files item once to select it; double-click or press Enter to open it.
- Right-click an item for its relevant actions. Empty space has its own menu.
- Files keeps Back, Forward, Up, an editable location, Places and clear item selection.
  Small windows keep commands in Actions rather than hiding their functionality.
- Start offers local search, real app icons, pins and configurable categories. Escape
  first clears a search and then closes Start. Removing a pin keeps its application.
- The taskbar groups an app's windows. Choose a numbered window when several are open;
  More apps keeps overflow reachable. Right-click exposes relevant window/pin actions.
- Drag a title bar, use its window buttons, Alt+Tab, or Arrange windows. Escape cancels
  an active move; snapping and restoring preserve each window's own normal rectangle.
- Copy, Cut, Paste and reviewed conflicts use real files. Cancel keeps confirmed
  completed items and explains unfinished work. Recycle Bin supports reviewed restore.
- USB drives select before opening. Copy to Downloads imports supported files; native
  To USB exports are create-only. Use Safe remove before unplugging. Reconnected
  devices require their own explicit selection instead of inheriting another lease.
- Open/Save as are owner-bound dialogs. Replacement, unsaved work and extraction
  destinations have explicit choices. Cancelling keeps the original document.

## Make it yours

Settings has Appearance, Display, Input, System and Accessibility. Appearance and
size changes are previews until Apply; Cancel/closing restore the previous choice.
Keyboard/click timing and accessibility save independently. High contrast reuses
an explicit palette; reduced effects removes decorative movement and shadows.
Tab/Shift+Tab move visible focus, F6/Shift+F6 change panes, and F1 describes the
currently focused control. This is not an external screen-reader protocol.

Optional applications can be installed and removed separately. A minimal installation
still has its base-owned desktop, Settings and first-use guide. Distribution profiles
retain their documented validation and customization boundaries.

## Tested release scope

The final acceptance binds the exact ISO/VMware ZIP to its compiled source inputs.
It records real installation and independent startup, ordinary/compact/150%/physical
4K pages, files/dialogs/desktop/tray tasks, error and recovery cases, and bounded
current/peak/retained memory. All named VMware controller profiles and the supported
original 7-Zip console MSI lifecycle have their own fresh evidence.

The 64-MiB QEMU UEFI profile attaches USB after installed startup. USB storage attached
before firmware boot at 64 MiB remains a recorded loader refusal, not a qualified
configuration. Use the prepared 128-MiB VMware package for the ordinary test route.
Advanced partition tools retain a logical 1024×768 requirement.

No universal/physical/ARM hardware, vendor GPU 3D, broader Windows compatibility or
participant usability-study result is claimed. Host-observed paint/event times include
instrumentation and emulation; they are not FPS or physical-device benchmarks.
