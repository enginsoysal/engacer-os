# Files views and ordering in M12.6

M12.6 is qualified within M12-STAGE6-VM-v1. Use its matching
[installation guide](install-m126.md), [release scope](../releases/m126-v0.12.6.md)
and official downloads.

Files keeps the [same navigation](files-m125.md). Use Icons or Details near the
address to switch views. In a small window, right-click the folder background
or a column heading and choose Use icon view or Use details view. Changing the
view does not open an item. Click once to select; double-click or press Enter
after selecting it to open it.

In a native folder, click Name, Type or Size to sort. Click that heading again
to reverse its direction. The small arrow marks the active order. Folders stay
first, and numbered names use a familiar order: File2 before File10. Your selected
items remain selected after sorting. Switching view reveals the focused selected
item in the new layout. The Sort menu also works in a narrow window.

Details prioritizes names. A small window retains Name and Size; Type appears
when there is enough room. Icons shows a shared large icon and two-line name.
Abbreviated names have a complete name tip when you point at them. Move away to
hide the tip. Properties remains available for supported selected objects.
An inactive window keeps its selection with a quieter highlight; click it to
work there again.

Type names follow filename associations, such as Text document for txt/md/log.
They do not guarantee the contents have that format. Sizes come from actual
files. A folder has a dash instead of an invented recursive size. This stage
does not show invented modification dates.

USB uses the same views, real names, types and sizes. Its existing directory
order stays unchanged; USB sorting is unavailable. Arrow keys move through its
icon grid, and Page controls show additional items. USB keeps its supported
FAT32 and one-file create-only copy limits. Use Safe remove before unplugging.

Native folders remember up to 32 view/order choices. Your USB view preference
is separate from a drive's identity: it never changes which device an old
location refers to. Missing preferences use Details. If saving a choice fails,
the view works for this session and explains that it could not be saved.

Files' minimum size retains its navigation and toolbar above its contents.
Enlarge the window for more columns or items. Actual 150% and 200% display choices
remain available in Settings; screenshots alone do not qualify all pointer or
accessibility behavior, which continues in M12.16.
