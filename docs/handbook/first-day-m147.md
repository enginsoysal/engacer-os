# Your first day with the M14.7 candidate

**Draft: full final qualification is running.** M14.6 remains the qualified public download. Use the guide matching your actual image.

Start with the [VMware installation steps](install-m147.md). Install into a separate disposable VM, finish the wizard and restart to the installed desktop. Source inspection or a live desktop is not a substitute for successful installed startup.

## Find your files

Open **My files** or **Documents**. Click an item once to select it; double-click or press Enter to open it. Use Back, Forward, Up or the address field to navigate. Keep personal documents separate from application installation folders.

Optional native tools remain independently removable. Removing Calculator does not remove Files, Settings or the desktop. Appearance and supported distribution choices remain under your control.

## Try original Windows installation

Open **Windows Apps** from Start. The included 7-Zip MSI supports console archive tasks and the previously qualified graphical previews. The new reusable engine also installs and removes the original pinned Notepad++ x64 MSI. Read [the MSI walkthrough](windows-m147.md): reviewing, installing and actually using an application are distinct capabilities.

The Notepad++ editor and SumatraPDF interface are not supported user tasks yet. Browser choices can download the qualified Firefox installer; they do not make Firefox run.

## Remove or recover an application

Choose **Windows Apps > Installed apps**, select the application, then **Remove app**. Follow the confirmation and wait for completion. Its checked saved installer supports removal after the original download is gone.

Changed application files remain in **Documents > Recovered applications**, with text records identifying their original locations. A later reinstall keeps those saved files separate. If a task was interrupted, use **Recover app** and read **Details** if its records need inspection.

## Understand the scope

The exact qualified image, resource figures and complete public delivery will be recorded in the M14.7 release notes after acceptance. Current development evidence is in the [milestone record](../milestones/m14-7.md). Configured guest RAM, fixed kernel state, framebuffer storage and owned task memory are separate measurements. Whole-system optimization remains a final M14.15 gate.
