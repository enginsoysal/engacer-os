## What this delivery qualifies

M11.6 brings the guided eight-step installer, real Files operations, customizable
Start/taskbar, window commands and saved appearance together on one frozen ISO.
The final regression repeats installation and actual installed startup, keyboard
and pointer tasks, ordinary/150%/real-4K rendering, device and removable-media
tasks, original 7-Zip MSI/console lifecycle and enabled-device VMware controller
profiles. Earlier stage passes do not qualify these final bytes.

Ctrl+Escape now cancels a captured file drag before Start handles the shortcut.
Without a captured interaction, Ctrl+Escape still opens Start. The final
regression includes both USB and PS/2 routes and checks source preservation.

## Qualification boundaries

The passing controller matrix covers SATA, IDE, LSI Logic, SAS1068, PVSCSI and
NVMe with BIOS and UEFI, plus BusLogic with BIOS. The exact shipped SATA/UEFI
starter is a separate profile. Every profile retains shipped devices and uses
the same disk and firmware variables for retained-ISO restart and two disk-only
boots, without forcing firmware boot order.

The original-application profile is **7-Zip 26.06 x64 MSI and console support**.
It is a digest-pinned MSI adapter and selected Win64 APIs, not general Windows
Installer compatibility. Windows GUI, shell extensions, Steam gaming, DirectX,
arbitrary MS-DOS/Windows applications and vendor GPU 3D remain unavailable.
Named VM evidence does not establish physical, ARM or universal device support.

The 64-MiB OVMF journey connects USB storage after installed startup. USB storage
attached before firmware boot remains a separately recorded unqualified topology.
The distributed VMware starter uses 128 MiB.

OS installation uses the **whole selected supported disk**, with verified
read/write/flush, 512-byte sectors and capacity 2 GiB–2 TiB. Disk tools expose
supported partition create/delete and quick format with separate consent.
Selected-partition OS installation, resizing, dual boot and secure erasure are
not implemented. Use disposable virtual disks for testing.

The interface is English; layouts are US QWERTY/Dvorak and time is UTC. There is
one local account without authentication or native ACLs. Optional apps can be
omitted/removed without breaking required desktop services; their offline cache
and pre-existing kernel handlers remain. Recovery is same-build, not a general
cross-release migration facility. Keep the matching ISO.

## Resource observations

[Measured resources](../../evidence/M11/6/resources.json) record 543,828 bytes of
fixed desktop BSS/data, unchanged from M11.5 and 423,484 bytes above M11.1, below
the 512-KiB growth budget. Installed managed startup bytes are 4,288,512 at
ordinary size, 9,408,512 at 150%, 33,370,112 at native 4K and 3,338,240 in the
1024×768 VMware starter. The five initial allocation-failure counts are existing
intentional boot stress probes. Window movement, USB reconnect and offline
Calculator lifecycle retain no extra managed pages; idle paints stop and all
CPUs halt. Twelve cached/full native viewport comparisons match exactly.

## Resource and publication policy

Fixed desktop state, peak/retained managed pages, fonts, shared framebuffer and
configured guest RAM are distinct measurements. Actual 4K captures do not prove
accelerated 3D or smoothness on every device. Agent scenario review is not a
human usability study.

Large temporary build and VM files are kept outside OneDrive through the guarded
local build junction. Canonical source, Git history, accepted evidence and media
remain preserved. Official source, full release assets, manifests, notices,
original third-party source/license files and SHA256 checksums must be verified
as separate public delivery checks.
