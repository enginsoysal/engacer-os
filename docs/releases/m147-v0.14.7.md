The tested Notepad++ native install tasks peak at 4219 managed pages in the default profile and 4542 in the French profile; all eight install/remove/reinstall/remove tasks retain zero managed pages. These are task measurements, separate from fixed kernel data, framebuffer storage, caches and configured VM RAM. The desktop fixed-state increase from M14.6 is eight bytes. These are overlapping component scopes, not whole-system RAM totals or faster-than-Windows claims.
