## New installer tasks

The production engine reads original MSI tables, costs selected files/features, stages checked original payloads, records durable ownership and publishes registration after verification. It handles the original 7-Zip 26.06 and Notepad++ 8.9.9.1 x64 MSI profiles. Required original Notepad++ WiX bodies execute on native action threads with real child copy/delete operations. Unsupported required actions refuse before target changes.

Windows Apps provides a source chooser, read-only review, source-change refusal, confirmation, installed-app inventory and guided removal/recovery. An MSI opened from Files remains unreviewed until its package is checked. Installer completion does not claim the Notepad++ editor can run.

Removal uses the checked cached installer even after the original download has gone. Changed, unknown and differently cased language files are kept separately in Documents > Recovered applications. Durable completion cleanup can finish after the source cache and product root have already been removed.

Scoped native development evidence includes install/remove/reinstall, actual payload hashes, actual registry after/before images, independent restarts, preserved files, ordinary cancellation and explicit labelled I/O fault adapters. Private precondition/fault fixtures are identified separately from the production worker and final media.

## What remains outside this stage

Notepad++ editor operation, SumatraPDF installation/interface, full original graphical archive tasks and general Windows application compatibility remain later mandatory gates. Firefox is a verified installer download only. EXE installers, desktop association integration, required runtimes/COM and complete original-app work continue in M14.8-M14.12. Whole-system CPU/RAM/storage optimization still blocks final M14.15.

Original Windows instructions execute through Engacer OS's own kernel and compatibility APIs. An embedded Windows guest, host Windows Installer or replacement vendor DLL does not perform these tasks.
