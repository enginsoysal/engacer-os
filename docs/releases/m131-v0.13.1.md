## Scope and limits

The native gate binds 600 compiled input digests, ordinary/compact/150%/actual-4K control journeys, independent startup and the exact enabled-device SATA/UEFI VMware package. Agent visual review is separate from human usability research. The full M13 installer/controller/device/application regression is M13.12, with installation-specific matrix work in M13.4. Historical M12 tests do not qualify untested new media.

The fixed shell remains 553,452 bytes and font masks 251,248 bytes. The measured control tasks retain zero additional managed pages and halt when idle; firmware, framebuffers, fixed state and configured guest RAM remain separate accounting categories. This does not claim zero OS memory or a gaming GPU driver.

The website's opt-in same-page search and reader-task article navigation require their own live browser publication proof. Their locally passing tests are not a production receipt. Broader physical/ARM hardware, Secure Boot enrollment, vendor GPU 3D, Steam and general DOS/Windows apps remain outside this stage. The installer retains its existing whole-disk replacement model; data-preserving resize and dual boot are not claimed.
