## What changes

Original geometric text and horizontal/vertical/diagonal resize cursors follow the actual native hit targets and supported display scale. Hotspots retain input coordinates; signed clipping protects framebuffer bounds. Captions retain the arrow. Cursor shape adds four fixed core bytes, without bitmap or framebuffer allocation.

Opaque row and rounded-surface straight spans use bounded architectural fills. Shadows omit only pixels guaranteed covered by their immediately following opaque surface, retaining all antialiased corners and exterior shadow pixels. No extra buffer or retained state is added.

Cached window movement recomposes the old/new exposed union once instead of repainting overlapping border strips twice. Pixel comparisons verify the result against a full repaint at ordinary, 150% and physical-4K sizes, including partly off-screen positions. Existing move/resize cancellation, minimize/restore, snap ownership and retained dirty documents are preserved.

The bounded native pointer trace uses the validated existing HPET clock, 64 fixed samples and no idle worker. Desktop fixed state grows by 2,560 bytes against M13.8; USB receipt timestamps add 16 bytes outside that total. Configured guest RAM, framebuffer/shadow storage and managed peak/retained allocations are separate measurements.

## Performance scope

The prequalification method decision in the [stage record](../milestones/m13-9.md) separates native receipt-to-CPU/framebuffer/cursor completion from external display transport and physical scanout. Native processing budgets are 33.3 ms at 1080p and 50 ms at physical 4K, with independently observed exact requested window positions. External RFB latency/intervals are also published; unmet original external goals are not reported as passed, and no GPU FPS or physical refresh guarantee is made.

Native processing median/p95 is 12.817/16.665 ms at 1080p and 19.2955/31.007 ms at physical 4K. Both declared processing budgets pass, with all 32 timing positions matched and all 32 exact visible positions separately confirmed in each profile. The 10-Hz offered input stream does not prove 30/60-FPS throughput. External cadence targets remain unmet: the physical-4K RFB interval p95 is 195.364 ms, including transport and observer overhead. No external smoothness pass is claimed. The full native reports accompany the acceptance record.

## Known limits

This is scoped motion/cursor and functional startup qualification, not vendor 3D, universal hardware or general Windows app support. Very-low-resource direct rendering retains its legacy arrow fallback. Automated native tasks and agent visual review are separate from a human novice usability study.

One concurrent QEMU 4K window-task installation returned an AHCI quarantine/install failure. Its report is preserved; the independent 4K control installation and startups pass. The separate window-task journey uses an owned clone of that verified installation. This observation is not erased or claimed fixed; stability investigation resumes in M13.13. Earlier accepted M13.8 media remain unchanged.
