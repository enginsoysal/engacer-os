## What changes

Title bars share their drawing, pointer and keyboard geometry. The original app
icon opens the window menu. Minimize, Maximize/Restore and Close have visible
36-pixel-high targets, separate hover/press/focus states and measured labels.
Close uses white artwork on red. Monochrome Maximize/Restore cutouts are truly
transparent rather than paper-colored blocks. The existing 57 original icon
identities and native Inter remain shared.

Active/inactive windows have distinct captions, borders and title ink. Tab and
Enter use the same validated caption commands as a click. Normal bounds survive
maximize/restore. Existing signed movement, all resize directions, snapping and
keyboard window commands remain. The app menu clamps a negative window anchor
before unsigned screen fitting. Selecting the desktop prevents Alt+F4 and
Alt+Space from targeting a background app. Close preserves the existing unsaved
review; file dialogs block their owner rather than the entire desktop.

## Qualification boundary

The release requires matching native window journeys, real installation and
retained-ISO restart, two ordinary disk starts, actual 150% and 4K, exact shipped
VMware media, separate BIOS journeys and cached/full movement comparisons.
Host checks cover 53,982,630 geometry points, 384 styles, 731,264 tinted pixels
and the existing 57-icon geometry/raster oracle. These supplement native observations.
Memory evidence distinguishes linked shell state, managed pages and configured
VM RAM. No new per-window framebuffer, raster cache or idle timer is introduced.

The earlier M12.2 concurrent BIOS/AHCI timeout remains open. Its fresh repeat
passes, but the trigger is not isolated and stress reliability is unqualified.
Final comprehensive regression remains M12.18. Physical hardware, ARM, vendor
GPU 3D and universal DOS/Windows application compatibility are not qualified by
this stage. Agent visual/scenario review is not a human usability study.

Linked fixed desktop BSS/data is **544,212 bytes**, **16 bytes** above M12.3.
Window tasks retain zero managed pages and no new allocation failures; idle
CPUs halt. Inter coverage remains **251,248 bytes**. The icon renderer uses a
**512-byte transient row**, no raster cache and no new heap allocation.
[Resources](../../evidence/M12/4/resources.json) distinguish these measurements
from configured RAM and total kernel consumption. Observer timings are not FPS.

The shared window-menu helper footer still uses bounded ellipsis; complete
fitting is carried to M12.14. Native HiDPI captures motivate a cursor-versus-hit
coordinate check in M12.16: caption actions run at the real scale, but scripted
clicks alone do not qualify pointer usability. Those follow-ups remain explicit
before final M12.18 qualification.
