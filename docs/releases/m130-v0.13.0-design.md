# M13.0 — Product design and documentation portal

Design-only delivery. No new native ISO is supplied. The qualified OS remains M12.18 and its immutable ISO/VMware package. This release cannot qualify native M13 controls, animation, GPU behavior or general Windows compatibility.

## Included

- Ordered M13.0–M13.12 plan with deliver/how/why/acceptance and per-stage GitHub/actual website gates.
- Source-backed M12.18 gap inventory, original setup/disk/desktop/Start/Settings/portal SVGs, shared design tokens and explicit reference performance targets.
- Current task-first documentation index, ordered Start/Install/Use/Customize/Project route pages, naturally ordered complete archive, stable historical URLs and matching M12.18 download identity.
- Interactive offline same-page search design: real curated public-guide links, keyboard selection, Enter, Escape/focus return, archive opt-in, no-result state and mobile layout.
- Explicit BrixCanvas capability assessment: production overlay and renderer-side sidebar/curated pagination remain pending. Existing public `/search` continues to work. A local prototype is not an implemented production overlay.

## Review and use

Read the [M13 plan](../milestones/m13.md), [visual contract and concept gallery](../architecture/desktop-m13.md) and [portal/search contract](../architecture/website-m13.md). The design ZIP contains original concepts and a small interactive prototype. Extract it, run `python -m http.server 8793 --bind 127.0.0.1` from its root, then open `http://127.0.0.1:8793/website/design-m13/search-prototype.html`. This loopback server is only for reviewing the prototype, not production hosting.

The original design prerelease remains immutable. The final design refinement is published separately as `m130-v0.13.0-design.1`, with its own source, ZIP and SHA256. Thirty-five publisher/ownership, ordering, archive-retention and immutable-download-selection tests accompany closure, plus sixteen prototype browser checks. Real browser observations cover the prototype and final public portal; they are design/content evidence, not native OS tests or a human novice study. The native homepage Save and public task/source/download/mobile/fallback-search checks pass, with 432 crawled pages and 275 exact-source articles. [Publication receipt](../../evidence/M13/0/publication-results.json). Production overlay and sidebar remain M13.1 work.

Later native stages require new immutable OS media and actual whole-task qualification before any implementation claim. M13.12 closes the dedicated appearance program; hardware recognition then takes priority.
