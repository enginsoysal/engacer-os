## Native changes

Disk tools use the same smooth typography, light setup palette and stable outer frame. The bordered partition/free-space list retains actual names, sizes, format and protection. Only suitable selected targets enable create/format/delete; destructive Apply is unavailable until explicit consent. Review repeats the exact disk and partition. Cancel stays a safe primary route.

Activate a size/name field and type to replace its suggested value; Ctrl+A selects it again. The bounded name accepts spaces. Actual operation completion uses normal ink, while errors retain warning ink. No fake formatting percentage, per-partition process or second framebuffer is added.

## Qualification scope

[Native acceptance](../../evidence/M13/3/acceptance-results.json), [resource measurements](../../evidence/M13/3/resources.json) and [visual review](../../evidence/M13/3/visual-review.json) bind the exact build. Disk-tool lifecycle profiles name QEMU SATA/AHCI, IDE, LSI SAS mptsas, NVMe and VirtIO block. The exact enabled-device SATA/UEFI VMware ZIP is tested separately. The full named controller/firmware installation and independent-startup matrix belongs to M13.4; historical tests do not qualify these new bytes.

The known QEMU-PVSCSI refusal remains unqualified for disk operations. A separate negative test checks readable refusal and unchanged bytes; the original failed positive attempt is preserved. This is distinct from VMware PVSCSI and does not weaken completion validation.

A BIOS protection/repair fixture verifies damaged metadata at startup, explicit verified-copy repair, protected action exclusion and unchanged bytes outside GPT metadata and on the other disk. Earlier UEFI fixture attempts found a valid backup by inspection time and did not qualify repair; those diagnostics remain visible. Agent visual/scenario review is not a human novice study.

## Resources and limits

Fixed desktop state remains 553,452 bytes; shared immutable font masks remain 251,248 bytes. Installer fixed state is 48,396 bytes, 27 bytes above M13.2. Repeated real disk operations and return to setup are measured for retained allocator pages and idle CPU halt. Configured guest RAM, fixed state, framebuffer storage and managed current/peak allocations are separate categories.

Disk tools prepare data partitions. Engacer OS installation still uses the whole selected disk and fresh explicit replacement consent. Resizing, filesystem conversion and data-preserving dual boot are unavailable. Quick format, delete and clear are not secure erasure. These unsigned development media use Secure Boot off. Universal/physical hardware, vendor GPU 3D, Steam and general DOS/Windows compatibility remain unqualified.
