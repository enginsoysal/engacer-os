# Engacer OS M14.10 / 0.14.10

This release gives the qualified Windows x64 application bundles separate files, DLLs, registry records, and temporary storage. A kernel-owned product GUID and durable installation generation follow child processes. Reinstallation advances the generation so old capabilities cannot authorize work in the new installation.

The native two-app test installed 7-Zip and Notepad++ MSI bundles and ran Windows executables in both. It updated and repaired the 7-Zip bundle, removed it, and cold-started the remaining Notepad++ bundle. The remaining bundle retained 241 checked files and backing identities, including nine migrated registry values. The fixture tests exact native DLL and registry behavior through Windows probes. The Notepad++ editor remains outside this qualification.

The native PE32 test starts an i386 helper from a Win64 parent. It checks the app-private SysWOW64 view, both machine registry views, successful exception continuation and the exit status for an unhandled fault. The supported helper ABI is bounded. Standalone x86 products and general Windows application compatibility remain future work.

MSI repair restores verified payloads from the cached installer. MSI update accepts a reviewed newer package for the same product with matching authored layout and registration, replaces verified package files, and keeps app state. Arbitrary installer upgrades are outside this profile.

## Install and verify

Download the matching ISO or VMware starter and SHA-256 list from the GitHub release. The starter contains a blank SATA disk. Open the VM with its ISO attached and follow the installer. Keep Secure Boot off and use a disposable disk. After installation, disconnect the ISO to boot from the installed disk.
