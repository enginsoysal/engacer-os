## What changes

Start replaces letter badges with original recognizable app icons. Application
identities also appear on the taskbar and title bars. Folders, supported file
types, shortcut overlays, USB rows, device categories and shared actions use the
same original geometric library. Names and established selection/activation
behavior remain. Broader desktop, Files/USB and taskbar layout work follows in
the ordered M12 stages.

The 57 icons share **2,443 bytes** of read-only geometry/colors, one **512-byte
temporary row** and **zero raster-cache bytes**. Fixed desktop BSS/data remains
544,164 bytes; separate icon telemetry occupies a 32-byte storage span. Tested
icon previews retain no additional managed pages or app processes. Existing
font coverage remains 251,248 bytes. These are distinct measurements, not total
kernel consumption. [Resources](../../evidence/M12/2/resources.json) and
[implementation decisions](../architecture/icons-m122.md) give exact scope.

## What was checked and what remains

The exact enabled-device VMware ZIP installs and reaches its real installed
desktop, then boots twice without its ISO using the same firmware variables.
QEMU SATA/UEFI and BIOS have separate installation/retained-ISO/two-disk-boot
journeys. Actual 100/150/200% app-icon pixels match the host rasterizer in both
themes, including a real 3840×2160 framebuffer. Native file types, unknown
fallback, real FAT32 USB rows, safe removal, provider focus, scrolling, idle and
signed cached/full window movement pass. Independent file CRCs confirm that the
sample contents remain intact. Icon appearance does not qualify another file
decoder, GPU acceleration or Windows application runtime.

**Retained unresolved observation:** an earlier M12.2 candidate had an initial
concurrent BIOS installation hit the existing AHCI timeout and report failure;
a fresh repeat of that candidate passed its complete journey. The corrected
palette candidate has its own matching results. The trigger is not isolated. The failed report is
preserved under diagnostics. This stage does not qualify stress reliability;
final qualification must revisit this rather than treating the repeat as a fix.

The full controller/device/original-app regression remains **M12.18**. Physical
hardware, ARM, vendor GPU 3D, universal DOS/Windows compatibility and a human
usability study are not qualified. The homepage feature is an actual owned QEMU
installed-guest capture, distinct from the host artwork contact sheets.
