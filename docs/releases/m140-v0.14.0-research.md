# Engacer OS M14.0 - Original Windows x64 research

Use the corrected **research.2** archive. The first public research archive normalized one hashed receipt to different line endings. It remains historical and does not change any native media or app result. Research.2 preserves exact bytes and independently verifies every archived observer/corpus hash before publication.

**Research-only prerelease. No new ISO or new Windows GUI compatibility is claimed.** M13.13 remains the current native download. The owner authorized sixteen ordered stages through M14.15, with whole-OS CPU/RAM/HDD-SSD efficiency as a core requirement from the start. M14.14 is a labelled release candidate; M14.15 optimization blocks final release.

## What was completed

The [full M14 plan](../milestones/m14.md) records delivery, implementation choices, reasons and acceptance for M14.0-M14.15. The [architecture and measurement protocol](../architecture/windows-m14.md) defines cold/warm starts, complete app workloads, fixed/private/shared/peak/retained memory, CPU time, responsiveness, physical/logical I/O, drained writes, idle operation, twenty-cycle cleanup and no-regression gates. Unsupported GUI app performance is explicitly unmeasured.

Six original containers and 23 payload/embedded PE binaries are pinned. Twenty-five independent LLVM checks agree on machine type, loaded image size and direct/delayed imported module names for the payloads and executable installers. Original MSI databases, action sequences and Binary stream bytes are read without running their installers or custom actions. All 613 existing native build inputs and current media remain unchanged.

## Findings that change implementation

- The Notepad++ 8.9.9.1 x64-labelled EXE installer is itself x86 and belongs to M15. Its original x64 MSI is the M14 route, requiring genuine execution of its x64 WiX custom-action DLL and cmd/xcopy behavior.
- Notepad++'s loaded image is 8,613,888 bytes and SumatraPDF 3.6.1 is 20,840,448 bytes. Both exceed the current eight-MiB image limit; checked demand-backed larger mappings must be implemented in M14.1.
- 7-Zip 26.06 contains actual x64 GUI code plus optional x86 extensions/SFX payloads. Their presence must not be advertised as executable M14 support.

The three registered target profiles require original installation, actual app use, independently checked files, OS restart, removal and reinstall. Six deterministic input files have hashes for archive, editor and text/vector/image PDF tasks. Generating or parsing a fixture does not prove rendering or native compatibility.
