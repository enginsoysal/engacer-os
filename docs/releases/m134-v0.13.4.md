# Engacer OS M13.4 / 0.13.4 - Installation and installed startup

Status: development candidate; qualification and publication pending. M13.3 remains the public qualified download. See the [candidate installation and recovery guide](../handbook/install-m134.md).

Native changes include shared progress/result/recovery frames, real verified progress without invented time estimates, coalesced identical progress paints, explicit first-start instructions and capability-bound recovery. Disk capacities account for observed sector width; unsupported installer formats remain refused.

Required before release: the fourteen named enabled-device VMware profiles, retained-ISO and two disk-only starts, persistent bytes, actual intermediate progress and failure/recovery, compact/scaled/physical 4K review, resource measurements, exact source and media binding. Development tests do not substitute for the complete qualification. Universal hardware, Secure Boot signing, vendor GPU 3D and general Windows compatibility remain outside this stage.
