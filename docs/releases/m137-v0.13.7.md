## What changes

Files has a compact common navigation/command frame, original place icons, a quiet 192-unit sidebar, clear page arrows and concise item/selection status. Small windows expose Places and More instead of overlapping controls. Breadcrumbs/address editing, details/icons, ordering, provider history and real file operations remain available. A single native folder opens in the same Files window through Enter/context Open, matching ordinary mouse navigation and preserving Back/Forward; desktop and explicit new-window launches remain separate.

Ctrl+F opens a bounded current-folder name filter. Case-insensitive displayed-name substring matching accepts up to 63 ASCII query bytes; it adds no background index, heap cache or process per keystroke. Each live window generation owns its query. Query changes clear hidden selection and scroll offset. Enter selects the first result without opening it; Escape clears the query before leaving the field. Clear/navigation/reuse and successful create/copy/move transitions are explicit; Refresh/sorting retain the same-folder query. Recycle Bin uses original displayed names and requires clearing a filter before Empty Bin.

USB filtering remains explicitly unavailable. Real supported USB navigation, long addresses, lease-bound detach/replacement, transfers and Eject retain provider/capability ownership. Eject follows the existing flush-before-removal path. Unsupported formats/search/hardware are not implied by the visual changes.
