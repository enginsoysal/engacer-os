## What changes

An eight-step original native wizard adds real keyboard/layout testing and
display size, individual optional-app choices and presets, editable local account
name, theme/accent/wallpaper, complete Review and a dismissible first-start guide.
Back retains choices and clears destructive consent. Required desktop components
remain independent of optional apps. The package cache permits offline reinstalls.

The installer verifies saved choices before activating the installed system.
Restart boots its real loader/kernel, including with the matching ISO retained.
Matching UEFI media provides a visible two-second Escape choice for setup/recovery.
Existing Files, Start/taskbar and window/appearance behavior remain available.

## Qualification boundaries

M11-STAGE5-VM-v1 concerns expanded setup and first installed startup. The full
controller/device/original-Windows-app regression matrix remains M11.6. The old
M10 controller matrix does not qualify these new bytes. Named virtual results
do not establish universal devices, physical hardware, ARM, vendor GPU 3D,
Steam gaming or general MS-DOS/Windows compatibility.

Installation uses the whole chosen disk with verified read/write/flush,
512-byte sectors and capacity 2 GiB–2 TiB. Disk tools provide supported partition
create/delete and quick-format operations with separate consent. Selected-
partition OS installation, resizing and dual boot are unavailable. Quick format
is not secure erasure. Do not use a development host disk as a test target.

The interface is English, layouts are US QWERTY/Dvorak and the clock uses UTC.
Names use 31 ASCII letters/digits/underscore/hyphen. The full offline app cache
and pre-existing kernel handlers remain even when optional executables are
omitted; this is not a claim of zero cache space or a smaller compiled kernel.
Appearance records keep the existing format. Prior same-build recovery still
has its documented slot/identity limits; the release is not a migration tool
for arbitrary old data formats. Retain the matching ISO for recovery.

Configured VM RAM, managed page measurements, fixed desktop state, shared
framebuffer and font coverage memory are distinct quantities. Real 4K buffers
are not proof of accelerated 3D or smoothness on every adapter. Agent scenario
review is not a usability study with children or older adults.

GitHub, the owner's temporary local `build` directory may be removed. Canonical
source, `.git`, English manuals and accepted evidence remain. Reproduction uses
the release source and pinned tools; it never overwrites accepted media in place.
