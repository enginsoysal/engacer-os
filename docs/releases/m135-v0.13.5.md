# Engacer OS M13.5 / 0.13.5 - Desktop and window experience

Status: development candidate; qualification and public delivery are in progress. M13.4 remains the qualified download. See the [desktop/window guide](../handbook/desktop-m135.md) and [installation guide](../handbook/install-m135.md).

Changes include original span-rendered wallpaper, a shared top-aligned icon grid, readable label backings, full-name feedback outside the grid, refined active/inactive window borders and exact snap feedback. A keyboard Move regression prevents an off-screen virtual grip from offering an unintended edge snap. The original failed development candidate is retained separately.

Required acceptance includes five display/control/install profiles, real pointer/keyboard window tasks and dirty-work ownership, independent desktop-file/reference persistence, exact enabled-device VMware startup, bounded resources and fresh public website verification. The M13.4 full controller matrix does not qualify these new media. Universal hardware, vendor GPU 3D and general Windows compatibility remain outside this appearance stage.
