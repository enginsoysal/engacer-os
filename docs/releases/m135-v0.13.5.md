## Native changes

An original folded-light wallpaper replaces the flat default presentation without loading another image or retaining another framebuffer. Solid and Horizon remain available; high contrast stays plain black. The desktop name banner is removed, the shared icon grid begins near the top and label backings preserve readability over customized colors. Longer-name feedback has a reserved strip above desktop paging, with matching damage tracking.

Window frames use restrained active/inactive hairlines with stronger high-contrast boundaries. Caption hit areas, ownership, tooltips and dirty-work reviews remain authoritative. Edge feedback describes the actual proposed rectangle and how to apply it. Odd-width right halves use the remaining screen width. Keyboard Move no longer mistakes an off-screen virtual grip for a real pointer at the right edge; explicit Win+Left/Right remain snap commands.
