## Resources and limits

Fixed desktop state remains 557,516 bytes (+0 from M13.11), installer state 48,412 bytes and font masks 251,248 bytes. Measured completed tasks retain zero managed pages; configured guest RAM, code, fixed state, framebuffers/shadow and managed peak/retained pages are separate. Independent stopped-image malformed-record cases make no within-session retention claim. No extra worker, framebuffer, cache or idle polling loop is added.

This is named virtual scope, not universal hardware, physical/ARM support, vendor GPU 3D, arbitrary MSI or general DOS/Windows compatibility. Original Windows support remains the pinned 7-Zip console profile. Screensaver is Off by default, consumes wake gestures and retains the workspace; it provides neither authentication nor display power management. Its one-minute timeout test is a feature check, not stability qualification. Automated scenarios and agent visual review are not a human novice study.
