# M12.18 final qualification

Status: candidate under qualification. M12.17 remains the complete public
qualified release until the final source/media/publication gates pass.

The final stage freezes one independent-kernel ISO and its prepared VMware
package. Earlier passing binaries do not qualify new bytes. Source hashes,
artifact hashes, exact guest input, independently stored files and actual native
framebuffer captures form separate evidence. No test uses the host disk or takes
over the host desktop.

## Final native scope

- Real guided installation, disk/partition operations, separate destructive
  consent, failure/retry/recovery, minimal optional apps and independent startup.
- Desktop icons/selection/shortcuts, common Files/provider navigation, views,
  copy/move/conflicts/cancellation/recycle, real app dialogs and independent files.
- Start/catalogue/pins, grouped taskbar, switching/snap/restore, provider-bound
  tray/network/audio/USB and optional-app independence.
- Keyboard-only routes, forward/reverse panes, visible current-focus semantics,
  Light/Dark/high contrast, supported compact/150%/4K scaling and reduced effects.
- Exact default-effect cached/full pixels, interrupted-move restoration, no new
  persistent raster state, separately measured current/peak/retained pages,
  bounded production host checks and all-CPU idle halt.
- Enabled-device VMware SATA, IDE, LSI Logic, LSI SAS 1068, PVSCSI and NVMe with
  BIOS and UEFI; BusLogic with BIOS; exact SATA/UEFI starter. No forced boot order.
- Original supported 7-Zip MSI install/run/archive/extract/remove/reinstall,
  independently verified original payload and document/archive bytes.
- Named input/USB/low-memory/firmware profiles, malformed/read-only/quota
  refusals, reconnect and an explicit repeat of concurrent BIOS/AHCI installs.

## Final visual carry

High-contrast picker and notification surfaces now have a two-pixel contrasting
outer boundary. Ordinary palettes keep their prior surfaces. The same existing
record and palette are reused; no persistent state, surface cache or worker is
added. Native captures and actual border pixels must verify the result.

## Honest limits and public closure

Screen-reader/speech protocols, universal or physical/ARM hardware, vendor GPU
3D and broader Windows application compatibility are not introduced. Named
negative/refused configurations remain explicitly unqualified, even when their
expected safe refusal is verified. Concurrent stress cannot prove a universal
absence of failures or identify an earlier unreproduced trigger by itself.

English installation, architecture, handbook, release and status documents must
match the final native scope. Verify public release source/notes/asset digests,
independently download the VMware ZIP and embedded ISO, explicitly save the native
BrixCanvas homepage, verify desktop/mobile/current manuals/search/archives, then
crawl all public HTTP links and perform fresh readback. Investigate the retained
custom-domain email-sharing observation separately; do not silently deploy a
shared BrixCanvas change outside the owner's approved scope.
