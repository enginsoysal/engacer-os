# Native Engacer recovery page

These version-independent native Brix exports keep the public 404 page branded
Engacer OS and offer the same Start here, Install, Use, Customize, Downloads and Search routes as the M13 portal, plus Home.
The response must retain HTTP 404; a branded recovery view is not a successful URL.

Use the owned Engacer BrixCanvas editor, open System pages / 404, and paste
`1.json` followed by `2.json` through Paste Brix. They are the menu and native
recovery content, in that order. Save explicitly and verify the public result.
The Home page keeps its separate four-root milestone composition.

The editor's global Header Button link is
`https://github.com/enginsoysal/engacer-os/releases/latest`. Header layout stays
None because this site supplies its own native Menu Brix. No shared BrixCanvas
platform change is required. The original public branding verification is recorded with M12.18; M13.0 aligns the menu with the task-first portal and verifies that the HTTP status remains 404.
